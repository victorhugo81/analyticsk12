Organization Files

info Instructions

  1. Download the CSV template using the button in the Templates tab below.
  2. Fill in all required columns for each row. Do not remove or rename column headers.
  3. If a record already exists, it will be updated. If not, a new record will be created.
  4. Any active user not found in an uploaded users.csv will be automatically marked Inactive.
  5. New users are assigned a random temporary password and will be required to change it on first login.
  6. Save your file as filename.csv (UTF-8 encoding) before uploading.
